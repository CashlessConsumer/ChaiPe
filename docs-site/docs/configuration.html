Basic Configuration

Learn the essential configuration options to get ChaiPe working on your website.

Required Parameters

Only two parameters are required to get started:

Parameter Type Description
upiId string Your UPI ID (e.g., yourname@upi)
name string Your display name (shown in payment apps)

Minimal Setup Example

Minimal Configuration 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name'
});

Common Configuration Mistakes

Wrong UPI ID Format

// Wrong - missing @ symbol
ChaiPe.init({
  upiId: 'yournameupi',
  name: 'Your Name'
});

// Wrong - uppercase
ChaiPe.init({
  upiId: 'YOURNAME@UPI',
  name: 'Your Name'
});

Correct UPI ID Format

// Correct - lowercase with @ symbol
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name'
});
⚠️
Important Notes
  • UPI IDs are case-sensitive and should be lowercase
  • The @ symbol is required
  • Test your UPI ID in a payment app before using in production
  • The name parameter appears in payment app when users tip

Theme Configuration

Customize the appearance of ChaiPe to match your brand and provide optimal user experience.

Choosing the Right Theme

ChaiPe offers three built-in themes, each designed for different use cases:

Theme Best For Characteristics
minimal Professional sites, blogs Clean, unobtrusive, blends with content
toast Notifications, quick tips Compact, slides from corner
floating Modern sites, apps Eye-catching, centered modal

Theme Customization Guide

You can customize colors, fonts, and spacing to match your brand.

Theme Customization

});

Trigger Configuration

Configure behavioral triggers to show payment nudge at optimal moments.

Understanding Behavioral Triggers

ChaiPe uses three types of behavioral triggers:

  • Scroll Depth: Shows nudge when user scrolls to a certain percentage of the page
  • Time on Page: Shows nudge after user spends a certain amount of time on the page
  • Exit Intent: Shows nudge when user is about to leave (desktop only)

Scroll Depth Best Practices

Scroll depth is the most effective trigger for long-form content like blog posts.

Content Type Recommended Scroll Depth Reasoning
Blog posts 70-80% User has consumed most content
Tutorials 60-70% User found value in tutorial
News articles 50-60% Quick reading, show earlier
Landing pages Not recommended Use manual trigger instead
Scroll Depth Configuration 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  triggers: {
    scrollDepth: 70  // Show at 70% scroll
  }
});

Time on Page Optimization

Time on page triggers work well for content that takes time to consume.

Content Length Recommended Time Reasoning
Short (5-10 min read) 90-120 seconds User has started reading
Medium (10-20 min read) 180-240 seconds User is engaged
Long (20+ min read) 300-360 seconds User has invested time
Time on Page Configuration 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  triggers: {
    timeOnPage: 180  // Show after 3 minutes (180 seconds)
  }
});

Exit Intent Usage

Exit intent triggers when user's mouse leaves the viewport (desktop only).

Exit Intent Configuration 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  triggers: {
    exitIntent: true  // Show when user tries to leave
  }
});
⚠️
Exit Intent Limitations
  • Only works on desktop (not mobile)
  • Can be intrusive if used frequently
  • Best for high-value content
  • Consider combining with other triggers

Conservative vs Aggressive Trigger Settings

Conservative (Recommended)

Show nudge later, less frequently. Better for user experience and brand reputation.

ChaiPe.init({
  triggers: {
    scrollDepth: 80,
    timeOnPage: 300,
    exitIntent: false
  }
});

Aggressive

Show nudge earlier, more frequently. Higher conversion but may annoy users.

ChaiPe.init({
  triggers: {
    scrollDepth: 50,
    timeOnPage: 60,
    exitIntent: true
  }
});

Trigger Combinations and Conflicts

You can combine multiple triggers. The first one to fire will show the nudge.

Combined Triggers 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  triggers: {
    // Show at 70% scroll OR after 2 minutes
    scrollDepth: 70,
    timeOnPage: 120,
    exitIntent: false
  }
});
💡
Trigger Tips
  • Test different trigger values to find optimal settings
  • Use analytics to measure conversion rates
  • Consider your audience when choosing triggers
  • A/B test different configurations
  • Monitor user feedback and adjust accordingly

Data Collection Configuration

Configure optional data collection from users who tip you.

Privacy Considerations

When collecting user data, consider:

  • Only collect data you actually need
  • Be transparent about why you're collecting data
  • Provide a clear privacy policy
  • Allow users to opt out of data collection
  • Store data securely and follow best practices

When to Collect Data

Data Type When to Collect Use Case
Email When you want to send updates or thank you Newsletter, updates, relationship building
Name When you want to personalize communication Personalized thank you messages
Phone Rarely needed, only if necessary Direct communication (use sparingly)
VPA When you want to track payment source Analytics, payment tracking
UTR For record-keeping and verification Payment tracking, disputes

Data Security Best Practices

  • Never store sensitive payment information
  • Encrypt data at rest and in transit
  • Use HTTPS for all data transmission
  • Implement proper access controls
  • Regularly review and update security practices
  • Comply with data protection regulations (GDPR, etc.)

GDPR Compliance Notes

If you have users from EU, you must comply with GDPR:

  • Obtain explicit consent for data collection
  • Provide clear information about data usage
  • Allow users to access and delete their data
  • Implement data protection measures
  • Have a Data Protection Officer if required
Data Collection Configuration 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  // Data collection options
  collectEmail: true,
  collectName: true,
  collectPhone: false,
  collectVPA: true,
  collectUPIUTR: true,
  
  // Optional: Make fields required
  requireEmail: false,
  requireName: false,
  
  // Optional: Custom labels
  emailLabel: 'Email (optional)',
  nameLabel: 'Name (optional)',
  utrLabel: 'UTR Number (for verification)'
});

Example Data Collection Setups

Minimal Collection (Recommended)

ChaiPe.init({
  collectUPIUTR: true  // Only collect UTR for record-keeping
});

Moderate Collection

ChaiPe.init({
  collectEmail: true,
  collectName: true,
  collectUPIUTR: true
});

Full Collection (Use Carefully)

ChaiPe.init({
  collectEmail: true,
  collectName: true,
  collectPhone: true,
  collectVPA: true,
  collectUPIUTR: true
});

TipJar Configuration

Configure the persistent TipJar for always-available tipping option.

TipJar vs Modal-Only Approach

Feature TipJar Modal Only
Always visible ✅ Yes ❌ No
Non-intrusive ✅ Yes ❌ No
Higher conversion ✅ Yes ❌ No
Best for Content sites, blogs Landing pages, quick actions

Positioning Strategies

Choose the best position for your TipJar based on your site layout.

Position Best For Visibility
bottom-right Most sites (default) High
bottom-left Sites with right sidebar High
top-right Mobile apps, dashboards Very High
top-left LTR languages with left nav Very High

Icon and Color Customization

TipJar Customization 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  
  tipJar: {
    enabled: true,
    mode: 'floating',
    position: 'bottom-right',
    
    // Appearance
    icon: '☕',
    label: 'Tip',
    size: 'medium',
    
    // Colors
    colors: {
      primary: '#4CAF50',
      secondary: '#45a049',
      text: '#ffffff'
    },
    
    // Animation
    animation: 'bounce'
  }
});

Auto-Show vs Manual Trigger

Auto-Show (Default)

TipJar appears automatically after a delay.

ChaiPe.init({
  tipJar: {
    enabled: true,
    autoShow: true,
    showDelay: 2000  // Show after 2 seconds
  }
});

Manual Trigger

TipJar is hidden until you call ChaiPe.showTipJar().

ChaiPe.init({
  tipJar: {
    enabled: true,
    autoShow: false
  }
});

// Show TipJar manually
document.getElementById('show-tipjar').addEventListener('click', () => {
  ChaiPe.showTipJar();
});

Mobile vs Desktop Behavior

TipJar works seamlessly on both mobile and desktop.

Feature Mobile Desktop
Position Bottom corners (thumb-friendly) Any corner
Size Large (44px+) Medium (36-44px)
Animation Subtle (fade) Any (bounce, slide, fade)
Click action Opens UPI app Opens modal with QR code

Animation Effects

Choose an animation effect for TipJar.

Animation Description Best For
fade Fades in smoothly Professional sites
slide Slides in from corner Modern sites
bounce Bounces on appearance Attention-grabbing
none No animation Minimalist sites
Animation Configuration 
ChaiPe.init({
  tipJar: {
    enabled: true,

  }

Performance Optimization

Optimize ChaiPe for fast loading and minimal impact on your site.

Lazy Loading ChaiPe

Load ChaiPe after your main content has loaded to improve initial page load time.

Lazy Loading 
// Load ChaiPe after page load
window.addEventListener('load', () => {
  const script = document.createElement('script');
  script.src = 'https://cdn.jsdelivr.net/npm/chaipe@latest/dist/chaipe.min.js';
  script.async = true;
  
  script.onload = () => {
    ChaiPe.init({
      upiId: 'yourname@upi',
      name: 'Your Name'
    });
  };
  
  document.body.appendChild(script);
});

Minimizing Bundle Size

ChaiPe is already optimized (~10KB minified), but you can further reduce impact:

  • Use CDN version (already minified)
  • Enable gzip compression on your server
  • Use browser caching for the script
  • Load from a fast CDN (jsdelivr is recommended)
Server Configuration for Caching 
# Apache .htaccess

  ExpiresActive On
  ExpiresByType application/javascript "access plus 1 year"


# Nginx
location ~* \.js$ {
  expires 1y;
  add_header Cache-Control "public, immutable";
}

Reducing Initialization Time

  • Only configure options you need
  • Avoid heavy callbacks in initialization
  • Use manual triggers when appropriate
  • Defer non-critical features
Optimized Initialization 
// Optimized - minimal configuration

// Add callbacks separately if needed
ChaiPe.onTipCompleted = (data) => {
  // Handle tip completion

Security Considerations

Implement proper security measures when using ChaiPe.

UPI ID Validation

Always validate UPI IDs before using them in production.

UPI ID Validation 
function validateUPIId(upiId) {
  // UPI ID format: username@provider
  const regex = /^[a-z0-9._-]+@[a-z0-9.-]+$/i;
  return regex.test(upiId);
}

// Usage
const upiId = 'yourname@upi';
if (validateUPIId(upiId)) {
  ChaiPe.init({
    upiId: upiId,
    name: 'Your Name'
  });
} else {
  console.error('Invalid UPI ID format');
}

Preventing XSS

ChaiPe is designed to prevent XSS, but follow these best practices:

  • Never inject user-provided data into ChaiPe configuration
  • Sanitize all user input before using it
  • Use Content Security Policy (CSP) headers
  • Keep ChaiPe updated to the latest version

Secure Data Handling

  • Never log sensitive payment information
  • Encrypt data at rest in your database
  • Use secure APIs for data transmission
  • Implement proper authentication and authorization
