TipJar Documentation

Learn about the TipJar feature - a persistent floating button that provides always-available tipping option for your users.

Overview

TipJar provides a persistent floating button that stays visible on the page, allowing users to tip at any time. Unlike behavioral nudges that appear at specific moments, TipJar is always available.

💡
TipJar vs Behavioral Nudges

TipJar: Always visible, non-intrusive, persistent access to tipping.

Behavioral Nudges: Appears at optimal moments (scroll, time, exit intent), shown once per session.

Best Practice: Use both! TipJar for always-available option + nudges for timely prompts.

Key Benefits

  • Always Available: Users can tip anytime without waiting for triggers
  • Non-Intrusive: Floating button doesn't interrupt reading flow
  • Higher Conversion: Persistent visibility increases tipping opportunities
  • Mobile-Friendly: Optimized for touch interactions on mobile devices
  • Customizable: Position, colors, size, icon, and animations

TipJar Modes

TipJar supports three different display modes for different use cases:

Floating Button (Default)

A floating button fixed to viewport corners. Best for most websites and blogs.

  • Always visible on screen
  • Non-intrusive, doesn't block content
  • Easy to access while scrolling
  • Works on both mobile and desktop

Inline Widget

Embed TipJar within your page content at a specific location.

  • Customizable placement in content
  • Blends with page layout
  • Good for article footers or sidebars
  • Can be shown/hidden programmatically

Custom Container

Use any element on your page as TipJar container.

  • Maximum flexibility in positioning
  • Integrates with existing UI elements
  • Perfect for custom layouts and designs
  • Full control over TipJar behavior

Configuration Options

Configure TipJar behavior and appearance with these options:

tipJar boolean optional

Enable TipJar feature. Set to true to show persistent tip button.

Enable TipJar 
ChaiPe.init({
  tipJar: true
});
tipJarPosition 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left' optional

Position of TipJar button on screen.

Position Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarPosition: 'bottom-right'  // Options: 'bottom-left', 'top-right', 'top-left'
});
tipJarSize 'small' | 'medium' | 'large' optional

Size of TipJar button.

Size Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarSize: 'medium'  // Options: 'small', 'medium', 'large'
});
tipJarColor string optional

Background color of TipJar button. Accepts hex, rgb, or named colors.

Color Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarColor: '#4CAF50'  // Green
  // Or: tipJarColor: '#ff6b6b'  // Red
  // Or: tipJarColor: '#667eea'  // Purple
});
tipJarIcon string optional

Icon or emoji displayed on TipJar button.

Icon Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarIcon: '☕'  // Coffee cup
  // Or: tipJarIcon: '💰'  // Money bag
  // Or: tipJarIcon: '❤️'  // Heart
});
tipJarText string optional

Text shown on hover or for larger TipJar buttons.

Text Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarText: 'Support Us'
  // Or: tipJarText: 'Buy me a chai'
});
tipJarAutoShow boolean optional

Automatically show TipJar after a delay. If false, you must manually call ChaiPe.showTipJar().

Auto-Show Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarAutoShow: true,
  tipJarShowDelay: 2000  // Show after 2 seconds
});
tipJarShowDelay number optional

Delay in milliseconds before auto-showing TipJar. Only used when tipJarAutoShow is true.

Show Delay Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarAutoShow: true,
  tipJarShowDelay: 3000  // Show after 3 seconds
});
tipJarShowOnMobile boolean optional

Show TipJar on mobile devices.

Mobile Visibility 
ChaiPe.init({
  tipJar: true,
  tipJarShowOnMobile: true
});
tipJarShowOnDesktop boolean optional

Show TipJar on desktop devices.

Desktop Visibility 
ChaiPe.init({
  tipJar: true,
  tipJarShowOnDesktop: true
});
tipJarAnimation 'fade' | 'slide' | 'bounce' | 'none' optional

Animation effect when TipJar appears.

Animation Configuration 
ChaiPe.init({
  tipJar: true,
  tipJarAnimation: 'bounce'  // Options: 'fade', 'slide', 'bounce', 'none'
});
tipJarContainer string | null optional

CSS selector for custom container element. Only used when tipJarMode is 'custom'.

Custom Container 
ChaiPe.init({
  tipJar: true,
  tipJarMode: 'custom',
  tipJarContainer: '#my-custom-container'
});
⚠️
TipJar vs Behavioral Nudges

TipJar and behavioral nudges are independent features. You can use both simultaneously for maximum conversion. TipJar provides always-available access, while nudges provide timely prompts at optimal moments.

API Methods

Control TipJar behavior programmatically with these methods:

ChaiPe.toggleTipJar()

Toggles TipJar visibility state. If TipJar is hidden, it will be shown. If it's visible, it will be hidden.

Toggle TipJar 
// Toggle button click handler
document.getElementById('toggle-tipjar').addEventListener('click', () => {
  ChaiPe.toggleTipJar();
});
ChaiPe.openTipJar()

Opens TipJar and displays payment modal. This is equivalent to clicking the TipJar button.

Open TipJar 
// Tip button click handler
document.getElementById('tip-now').addEventListener('click', () => {
  ChaiPe.openTipJar();
});
ChaiPe.closeTipJar()

Closes TipJar. This is different from hiding - it removes TipJar from DOM.

Close TipJar 
ChaiPe.closeTipJar();
ChaiPe.showTipJar()

Displays persistent TipJar button. Use this if you initially disabled TipJar or hid it programmatically.

Show TipJar 
// Show TipJar after user completes action
document.getElementById('read-more').addEventListener('click', () => {
  ChaiPe.showTipJar();
});
ChaiPe.hideTipJar()

Hides persistent TipJar button. Useful for temporarily removing button during specific user flows.

Hide TipJar 
// Hide TipJar during checkout
function startCheckout() {
  ChaiPe.hideTipJar();
  // ... checkout logic
}
ChaiPe.removeTipJar()

Removes TipJar from DOM completely. Use this when you want to permanently remove TipJar.

Remove TipJar 
ChaiPe.removeTipJar();
ChaiPe.updateTipJar(options)

Updates TipJar configuration dynamically without re-initializing ChaiPe. Accepts any TipJar configuration option.

Update TipJar 
// Change TipJar position and color
ChaiPe.updateTipJar({
  position: 'top-right',
  color: '#ff6b6b'
});

// Update multiple properties
ChaiPe.updateTipJar({
  icon: '💰',
  text: 'Support Us',
  size: 'large'
});

Event Callbacks

Track TipJar interactions with these event callbacks:

onTipJarShown(data)

Called when TipJar is displayed to user.

TipJar Shown Event 
ChaiPe.init({
  tipJar: true,
  onTipJarShown: (data) => {
    console.log('TipJar shown:', data.sessionId);
    analytics.track('TipJar Shown', { sessionId: data.sessionId });
  }
});
onTipJarDismissed(data)

Called when TipJar is dismissed or hidden.

TipJar Dismissed Event 
ChaiPe.init({
  tipJar: true,
  onTipJarDismissed: (data) => {
    console.log('TipJar dismissed:', data.sessionId);
    analytics.track('TipJar Dismissed', { sessionId: data.sessionId });
  }
});
onTipJarOpened(data)

Called when user clicks TipJar and opens payment modal.

TipJar Opened Event 
ChaiPe.init({
  tipJar: true,
  onTipJarOpened: (data) => {
    console.log('TipJar opened:', data.sessionId);
    analytics.track('TipJar Opened', { sessionId: data.sessionId });
  }
});

Examples

Basic TipJar Setup

Basic TipJar 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  tipJar: true
});

Customized TipJar

Customized TipJar 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  tipJar: {
    enabled: true,
    position: 'bottom-right',
    size: 'medium',
    color: '#4CAF50',
    icon: '☕',
    text: 'Support Us',
    autoShow: true,
    showDelay: 2000,
    animation: 'bounce'
  }
});

TipJar with Manual Trigger

Manual TipJar 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  tipJar: {
    enabled: true,
    autoShow: false  // Don't auto-show
  }
});

// Show TipJar manually
document.getElementById('show-tipjar').addEventListener('click', () => {
  ChaiPe.showTipJar();
});

Dynamic TipJar Updates

Dynamic Updates 
// Change TipJar based on user behavior
window.addEventListener('scroll', () => {
  const scrollPercent = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
  
  if (scrollPercent > 50) {
    ChaiPe.updateTipJar({
      size: 'large',
      color: '#10b981',
      text: 'Enjoyed? Tip us!'
    });
  }
});

Best Practices

Positioning Strategy

  • Bottom-Right (Default): Best for most websites, doesn't interfere with navigation
  • Bottom-Left: Good for sites with right sidebar
  • Top-Right: High visibility, good for dashboards
  • Top-Left: For LTR languages with left navigation

Size Guidelines

  • Small: Minimal footprint, good for clean designs
  • Medium (Default): Balanced visibility and footprint
  • Large: High visibility, good for conversion-focused pages

Animation Choice

  • None: No animation, minimalist approach
  • Fade: Subtle appearance, professional sites
  • Slide: Draws attention, modern sites
  • Bounce: Attention-grabbing, high-conversion pages

Color Selection

  • Match your brand colors for consistency
  • Ensure sufficient contrast for accessibility (WCAG AA: 4.5:1)
  • Test in both light and dark modes
  • Consider color psychology: green for positive actions, red for urgent

Mobile vs Desktop

  • Mobile: Use bottom corners for thumb accessibility
  • Desktop: Any corner works, consider user flow
  • Responsive: Consider different sizes for different screen sizes

Timing Strategy

  • Auto-Show Delay: 2-3 seconds is optimal for most sites
  • Content-Based: Show TipJar after user engages with content
  • Manual Trigger: Let users choose when to see TipJar
  • Avoid Overwhelming: Don't show TipJar immediately on page load
✅
TipJar Best Practices Checklist
  • ✅ Use appropriate position for your layout
  • ✅ Choose size that balances visibility and footprint
  • ✅ Match colors to your brand
  • ✅ Test on both mobile and desktop
  • ✅ Use subtle animation or none
  • ✅ Set reasonable auto-show delay (2-3 seconds)
  • ✅ Make TipJar non-intrusive but accessible
  • ✅ Track TipJar events for analytics
  • ✅ Consider combining with behavioral nudges
