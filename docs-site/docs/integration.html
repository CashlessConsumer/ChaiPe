Getting Started

Prerequisites

Before integrating ChaiPe, ensure you have:

  • UPI ID: A valid UPI ID (e.g., yourname@upi) to receive payments
  • Basic HTML/JS Knowledge: Understanding of HTML and JavaScript
  • Website Access: Ability to add scripts to your website
  • Modern Browser Support: ChaiPe works in all modern browsers (Chrome, Firefox, Safari, Edge)

Installation Methods

CDN (Recommended)

Fastest way to get started - no build tools required.

CDN Installation

npm

For projects using npm and build tools.

npm Installation 
# Install ChaiPe
npm install chaipe

# Import and use
import { ChaiPe } from 'chaipe';

ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name'
});

Download

Download latest release from GitHub Releases and include it in your project.

Step-by-Step Setup Guide

  1. Include ChaiPe Script: Add script tag to your HTML (before closing tag)
  2. Initialize with Configuration: Call ChaiPe.init() with your UPI ID and preferences
  3. Configure Triggers: Set scroll depth and time on page for behavioral nudging
  4. Customize Appearance: Choose a theme and customize colors to match your brand
  5. Test Integration: Test on both mobile and desktop devices
  6. Deploy: Push changes to production

Testing Your Integration

Before going live, test your integration:

  • Mobile Testing: Verify UPI deep links open correctly in payment apps
  • Desktop Testing: Ensure QR code displays and is scannable
  • Trigger Testing: Scroll to trigger depth and wait for time triggers
  • Theme Testing: Test all themes in both light and dark mode
  • Callback Testing: Verify event callbacks fire correctly

Blog Integration

Learn how to add ChaiPe to your blog for monetizing long-form content.

Adding ChaiPe to a Blog Post

The most effective integration for blogs is to trigger nudge when readers have consumed most of your content.

Blog Post Integration

Scroll-Based Trigger Configuration

Scroll depth triggers are ideal for blog posts because they indicate content consumption.

💡
Optimal Scroll Depth

For blog posts, 70-80% scroll depth works best. This ensures readers have consumed most content before seeing nudge.

Scroll Trigger Configuration 
// Conservative - show later
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  triggers: {
    scrollDepth: 80  // Show at 80% scroll
  }
});

// Moderate (recommended)
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  triggers: {
    scrollDepth: 70  // Show at 70% scroll
  }
});

// Aggressive - show earlier
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  triggers: {
    scrollDepth: 50  // Show at 50% scroll
  }
});

Time-Based Trigger Configuration

Time on page triggers work well for in-depth articles that take time to read.

Time Trigger Configuration

  }

// For medium articles (10-20 min read)

  upiId: 'yourname@upi',
  name: 'Your Name',
  triggers: {
    timeOnPage: 180  // 3 minutes
  }
});

// For long articles (20+ min read)
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',

  }
});

Best Practices for Blog Content

  • Match Article Length: Adjust trigger thresholds based on article length
  • Use TipJar: Add persistent tip jar for readers who want to tip later
  • Customize Message: Tailor nudge message to your content
  • Collect Minimal Data: Only collect information you actually need
  • Test Different Amounts: Experiment with tip amounts to find optimal range
  • Track Analytics: Use callbacks to understand what works for your audience

Tips for Maximizing Conversion

🎯
Conversion Optimization Tips
  • Use authentic, personal messages instead of generic ones
  • Trigger after users have received value (not before)
  • Offer a "recommended" amount with social proof
  • Make tipping optional and guilt-free
  • Follow up with thank you messages when possible

Single Page Application (SPA) Integration

Integrate ChaiPe into React, Vue.js, Angular, and other SPAs with proper lifecycle management.

React Integration

Use React hooks to manage ChaiPe initialization and lifecycle.

React Hook Example 
import { useEffect, useRef } from 'react';

function useChaiPe(config) {
  const initializedRef = useRef(false);

  useEffect(() => {
    // Load ChaiPe script dynamically
    const script = document.createElement('script');
    script.src = 'https://cdn.jsdelivr.net/npm/chaipe@latest/dist/chaipe.min.js';
    script.async = true;
    
    script.onload = () => {
      // Initialize ChaiPe
      if (window.ChaiPe && !initializedRef.current) {
        window.ChaiPe.init(config);
        initializedRef.current = true;
      }
    };

    document.body.appendChild(script);

    // Cleanup on unmount
    return () => {
      // Remove ChaiPe modal if visible
      if (window.ChaiPe) {
        window.ChaiPe.dismiss();
      }
    };
  }, [config]);

  return { initializedRef };
}

Angular Integration

Use Angular services for ChaiPe integration with dependency injection.

Angular Service Example 
// chaipe.service.ts
import { Injectable } from '@angular/core';

declare global {
  interface Window {
    ChaiPe?: any;
  }
}

const _window = window as unknown as Window;

@Injectable({
  providedIn: 'root'
})
export class ChaiPeService {
  private initialized = false;

  init(config: any) {
    if (!this.initialized && _window.ChaiPe) {
      _window.ChaiPe.init(config);
      this.initialized = true;
    }
  }

  show() {
    if (_window.ChaiPe) {
      _window.ChaiPe.show();
    }
  }

  dismiss() {
    if (_window.ChaiPe) {
      _window.ChaiPe.dismiss();
    }
  }
}

// In app.component.ts
import { Component, OnInit } from '@angular/core';
import { ChaiPeService } from './services/chaipe.service';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent implements OnInit {
  constructor(private chaisePeService: ChaiPeService) {}

  ngOnInit() {
    // Load ChaiPe script
    const script = document.createElement('script');
    script.src = 'https://cdn.jsdelivr.net/npm/chaipe@latest/dist/chaipe.min.js';
    script.async = true;
    
    script.onload = () => {
      this.chaisePeService.init({
        upiId: 'yourname@upi',
        name: 'Your Name',
        amounts: [10, 25, 50, 100],
        onTipCompleted: (data) => {
          console.log('Tip received:', data);
        }
      });
    };

    document.body.appendChild(script);
  }

  showModal() {
    this.chaisePeService.show();
  }
}

Managing Modal Lifecycle in SPAs

⚠️
Important SPA Considerations
  • Cleanup on Route Changes: Dismiss modal when navigating to new routes
  • Avoid Duplicate Initialization: Check if ChaiPe is already initialized before calling init()
  • Handle Component Unmount: Clean up ChaiPe when components unmount
  • Dynamic Script Loading: Load ChaiPe script dynamically to avoid issues with bundlers
Route Change Handler 
// React Router example
import { useEffect } from 'react';
import { useLocation } from 'react-router-dom';

function App() {
  const location = useLocation();

  useEffect(() => {
    // Dismiss modal when route changes
    if (window.ChaiPe) {
      window.ChaiPe.dismiss();
    }
  }, [location.pathname]);

  return ;
}

Advanced Integration Patterns

Explore advanced techniques for customizing and extending ChaiPe functionality.

Multiple Instances (Different UPI IDs)

Use different UPI IDs for different sections of your site.

Multiple UPI IDs 
// Blog posts - personal UPI
function initBlogChaiPe() {
  ChaiPe.init({
    upiId: 'personal@upi',
    name: 'Personal Blog',
    amounts: [10, 25, 50]
  });
}

// Tutorials - business UPI
function initTutorialChaiPe() {
  ChaiPe.init({
    upiId: 'business@upi',
    name: 'Business Tutorials',
    amounts: [50, 100, 200]
  });
}

// Use based on page type
if (window.location.pathname.startsWith('/blog')) {
  initBlogChaiPe();
} else if (window.location.pathname.startsWith('/tutorials')) {
  initTutorialChaiPe();
}

Dynamic Configuration Based on Content

Adjust ChaiPe configuration based on content type, author, or category.

Dynamic Configuration 
// Get content type from page
const contentType = document.body.dataset.contentType || 'default';

// Configuration based on content type
const configs = {
  blog: {
    upiId: 'personal@upi',
    name: 'Blog Author',
    amounts: [10, 25, 50],
    triggers: { scrollDepth: 70 }
  },
  tutorial: {
    upiId: 'business@upi',
    name: 'Business Tutorials',
    amounts: [50, 100, 200],
    triggers: { scrollDepth: 50 }
  },
  default: {
    upiId: 'main@upi',
    name: 'Site Name',
    amounts: [10, 25, 50, 100],
    manualOnly: true
  }
};

// Initialize with appropriate config
const config = configs[contentType] || configs.default;
ChaiPe.init(config);

A/B Testing Implementation

Test different configurations to optimize conversion rates.

A/B Testing 
// Simple A/B test with localStorage
const abTest = getABTestVariant('chaipe-config');

const configs = {
  A: {
    amounts: [10, 25, 50],
    message: 'Enjoying this?'
  },
  B: {
    amounts: [20, 50, 100],
    message: 'Found this helpful?'
  }
};

ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  ...configs[abTest],
  onTipCompleted: (data) => {
    // Track which variant converted
    analytics.track('Tip Completed', {
      variant: abTest,
      amount: data.amount
    });
  }
});

function getABTestVariant(testName) {
  const stored = localStorage.getItem(testName);
  if (stored) return stored;
  
  // Randomly assign variant
  const variants = ['A', 'B'];
  const variant = variants[Math.floor(Math.random() * variants.length)];
  localStorage.setItem(testName, variant);
  return variant;
}

Server-Side Tip Tracking

Send tip data to your server for record-keeping and analysis.

Server-Side Tracking 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  collectEmail: true,
  collectUPIUTR: true,
  
  onTipCompleted: async (data) => {
    // Send to your server
    try {
      const response = await fetch('/api/tips', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          amount: data.amount,
          sessionId: data.sessionId,
          email: data.customData?.email,
          name: data.customData?.name,
          utr: data.customData?.utr,
          timestamp: new Date().toISOString()
        })
      });

      if (!response.ok) {
        console.error('Failed to record tip');
      }
    } catch (error) {
      console.error('Error recording tip:', error);
    }
  }
});

Troubleshooting

Common issues and solutions for ChaiPe integration.

Common Issues and Solutions

Modal Not Appearing

Causes:

  • ChaiPe not initialized properly
  • Trigger conditions not met
  • Manual only mode enabled
  • JavaScript errors preventing execution

Solutions:

  • Check browser console for errors
  • Verify ChaiPe.init() is called
  • Check trigger values (scroll depth, time on page)
  • Ensure manualOnly is not set to true if you want automatic triggers

QR Code Not Showing

Causes:

  • Desktop device not detected correctly
  • QR code generation error
  • CSS hiding QR code element

Solutions:

  • Check user agent detection in browser console
  • Verify UPI ID is valid format
  • Check for CSS conflicts with .ChaiPe-qr-code class
  • Test on different browsers

UPI Link Not Working

Causes:

  • Invalid UPI ID format
  • UPI ID doesn't exist
  • Payment app not installed

Solutions:

  • Verify UPI ID format: username@provider
  • Test UPI ID in payment app directly
  • Check UPI link format in console
  • Ensure currency is set to INR

Best Practices

Follow these guidelines for optimal ChaiPe integration and user experience.

Do's and Don'ts

✅ Do's

  • Do test on both mobile and desktop devices
  • Do customize messages to match your brand voice
  • Do use appropriate trigger values for your content
  • Do collect only necessary information from users
  • Do track events with analytics for optimization
  • Do use TipJar for persistent access
  • Do make tipping optional and guilt-free
  • Do follow up with thank you messages when possible
  • Do test different tip amounts to find optimal range

❌ Don'ts

  • Don't show nudges immediately on page load
  • Don't make tipping mandatory or guilt-trip users
  • Don't collect unnecessary personal information
  • Don't use aggressive trigger values
  • Don't show false urgency or scarcity
  • Don't hide or make dismissing difficult
  • Don't initialize ChaiPe multiple times on same page
  • Don't block users from accessing your content
  • Don't use ChaiPe without proper testing

Performance Tips

  • Lazy Load: Load ChaiPe script after initial page content renders
  • Use CDN: Use CDN for fastest script loading
  • Minimize Configuration: Only configure what you need
  • Avoid Multiple Inits: Check if already initialized before calling init()
  • Cleanup in SPAs: Dismiss modal when navigating away

UX Recommendations

  • Match Brand: Use colors and fonts that match your site
  • Clear CTAs: Use clear, actionable button text
  • Appropriate Amounts: Offer amounts that make sense for your audience
  • Mobile-First: Design for mobile users (majority in India)
  • Accessible: Ensure sufficient contrast and touch targets
  • Fast Loading: Don't block page render with ChaiPe

Conversion Optimization

  • Trigger at Right Moment: After users have received value
  • Personalized Messages: Tailor to content type and audience
  • Social Proof: Show that others have tipped (if applicable)
  • Easy Dismissal: Make it easy to close without tipping
  • Follow Up: Thank users who tip to build relationships
  • A/B Test: Test different configurations to optimize
  • Analyze Data: Use analytics to understand what works

Accessibility Considerations

  • Keyboard Navigation: Ensure modal can be dismissed with Escape key
  • Screen Readers: Provide ARIA labels and descriptions
  • Color Contrast: Ensure sufficient contrast for readability
  • Touch Targets: Minimum 44x44px for mobile
  • Focus Management: Proper focus handling when modal opens/closes
