Configuration Options

Complete reference for all configuration parameters passed to ChaiPe.init(config).

💡
Type Annotations

Type annotations use TypeScript-style notation for clarity, but ChaiPe is pure JavaScript and doesn't require TypeScript.

Required Parameters

upiId string required

Your UPI ID (e.g., yourname@upi). This is the payment address where tips will be received.

Example 
ChaiPe.init({
  upiId: 'john.doe@okaxis'
});
Note: Must be a valid UPI ID format (username@provider). Common providers include @okaxis, @ybl, @upi, @icici, @hdfc.
name string required

Display name shown in payment prompts and UPI apps. This helps users identify who they're paying.

Example 
ChaiPe.init({
  name: 'John Doe'
});
Default: 'Creator'

Core Configuration Options

amounts number[] optional

Array of preset tip amounts in rupees. These amounts will be displayed as clickable buttons in the payment modal.

Example 
ChaiPe.init({
  amounts: [10, 25, 50, 100]
});
Default: [10, 25, 50, 100]
Note: Minimum amount is ₹1. Amounts should be in ascending order for better UX.
theme 'minimal' | 'toast' | 'floating' optional

Visual theme for the payment modal. Each theme has a different appearance and behavior.

Example 
ChaiPe.init({
  theme: 'minimal'
});
Default: 'minimal'
Options:
  • minimal - Clean, centered modal with subtle design
  • toast - Compact notification-style modal
  • floating - Floating modal with shadow, more prominent
message string optional

Nudge message displayed to users when the modal appears. This is the main text that encourages users to tip.

Example 
ChaiPe.init({
  message: 'Enjoying the content? Consider supporting us!'
});
Default: 'Enjoying the content?'
buttonText string optional

Text displayed on the primary action button in the modal.

Example 
ChaiPe.init({
  buttonText: 'Support Our Work'
});
Default: 'Buy me a coffee ☕'
currency string optional

Currency code for payments. Currently only INR is supported.

Example 
ChaiPe.init({
  currency: 'INR'
});
Default: 'INR'
Warning: Only INR is currently supported. Other currencies will not work with UPI.
darkMode boolean optional

Force dark mode on or off. If not specified, the theme will automatically adapt based on user's system preference.

Example 
ChaiPe.init({
  darkMode: true
});
Default: undefined (auto-detect from system preference)
manualOnly boolean optional

If true, the modal will only show when manually triggered via ChaiPe.show(). All automatic triggers (scroll, time, exit intent) will be disabled.

Example 
ChaiPe.init({
  manualOnly: true
});

// Show modal manually
document.getElementById('tip-button').addEventListener('click', () => {
  ChaiPe.show();
});
Default: false

Trigger Configuration

Configure when the behavioral nudge modal should appear automatically.

triggers.scrollDepth number | null optional

Trigger the modal when the user scrolls to a specified percentage of the page.

Example 
ChaiPe.init({
  triggers: {
    scrollDepth: 70  // Show at 70% scroll
  }
});
Default: 70
Range: 0-100
Note: Set to null to disable this trigger.
triggers.timeOnPage number | null optional

Trigger the modal after the user has spent a specified amount of time on the page.

Example 
ChaiPe.init({
  triggers: {
    timeOnPage: 120  // Show after 2 minutes
  }
});
Default: 120 (2 minutes)
Unit: seconds
Note: Set to null to disable this trigger.
triggers.exitIntent boolean optional

Enable exit intent detection to show the modal when the user is about to leave the page (desktop only).

Example 
ChaiPe.init({
  triggers: {
    exitIntent: true
  }
});
Default: false
Note: Only works on desktop devices. Mobile devices don't support exit intent detection.
⚠️
Trigger Behavior

The nudge will show when any of the enabled triggers are met. Set a value to null to disable a specific trigger. The modal will only show once per page load.

Data Collection Options

Optionally collect additional information from users when they complete a payment. All fields are optional for users.

collectEmail boolean optional

Show an optional email field in the payment modal. Useful for newsletter integration or follow-up.

Example 
ChaiPe.init({
  collectEmail: true,
  onTipCompleted: (data) => {
    console.log('Email:', data.customData.email);
  }
});
Default: false
Note: Users can skip providing their email.
collectName boolean optional

Show an optional name field in the payment modal. Useful for personal acknowledgment.

Example 
ChaiPe.init({
  collectName: true,
  onTipCompleted: (data) => {
    console.log('Name:', data.customData.name);
  }
});
Default: false
collectPhoneNumber boolean optional

Show an optional phone number field in the payment modal.

Example 
ChaiPe.init({
  collectPhoneNumber: true
});
Default: false
collectVPA boolean optional

Show an optional VPA (UPI ID) field in the payment modal. Useful for tracking which UPI app the user used.

Example 
ChaiPe.init({
  collectVPA: true
});
Default: false
collectUPIUTR boolean optional

Show an optional UPI Transaction ID (UTR) field in the payment modal. Useful for record-keeping and verification.

Example 
ChaiPe.init({
  collectUPIUTR: true,
  onTipCompleted: (data) => {
    console.log('UTR:', data.customData.utr);
  }
});
Default: false
Recommended: Enable this for better record-keeping

TipJar Configuration

TipJar provides a persistent payment button that's always visible on the page.

tipJar boolean optional

Enable the persistent tip jar button that floats on the page.

Example 
ChaiPe.init({
  tipJar: true
});
Default: false
See: TipJar Documentation for complete details
tipJarPosition 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left' optional

Position of the tip jar button on the screen.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarPosition: 'bottom-left'
});
Default: 'bottom-right'
tipJarSize 'small' | 'medium' | 'large' optional

Size of the tip jar button.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarSize: 'large'
});
Default: 'medium'
tipJarColor string optional

Background color of the tip jar button. Accepts hex, rgb, or named colors.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarColor: '#ff6b6b'
});
Default: '#4CAF50'
tipJarIcon string optional

Icon or emoji displayed on the tip jar button.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarIcon: '💰'
});
Default: '☕'
tipJarText string optional

Text shown on hover or for larger tip jar buttons.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarText: 'Support Us'
});
Default: 'Buy me a chai ☕'
tipJarAutoShow boolean optional

Automatically show the tip jar after a delay. If false, you must manually call ChaiPe.showTipJar().

Example 
ChaiPe.init({
  tipJar: true,
  tipJarAutoShow: true,
  tipJarShowDelay: 2000
});
Default: true
tipJarShowDelay number optional

Delay in milliseconds before auto-showing the tip jar.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarShowDelay: 3000  // 3 seconds
});
Default: 2000 (2 seconds)
tipJarShowOnMobile boolean optional

Show tip jar on mobile devices.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarShowOnMobile: true
});
Default: true
tipJarShowOnDesktop boolean optional

Show tip jar on desktop devices.

Example 
ChaiPe.init({
  tipJar: true,
  tipJarShowOnDesktop: true
});
Default: true

Public Methods

Complete documentation for all public API methods available on the ChaiPe object.

ChaiPe.init(config)

Initializes ChaiPe with the provided configuration. Creates a singleton instance that is reused on subsequent calls.

Parameters

  • config (ChaiPeConfig) - Configuration object with all options

Returns

undefined

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  amounts: [10, 25, 50, 100],
  theme: 'minimal'
});
Note: Subsequent calls to init() will reuse the existing instance. To reinitialize, you must reload the page.
ChaiPe.show()

Manually displays the tip modal. Useful for custom triggers or user-initiated actions.

Parameters

None

Returns

undefined

Example

Example 
document.getElementById('tip-button').addEventListener('click', () => {
  ChaiPe.show();
});
Note: The modal will only show once per page load unless dismissed.
ChaiPe.dismiss()

Dismisses/hides the currently visible tip modal.

Parameters

None

Returns

undefined

Example

Example 
ChaiPe.dismiss();
ChaiPe.confirmPayment(amount)

Confirms that a payment was completed. This method is typically called automatically by the library when the user confirms payment, but can be called manually if needed.

Parameters

  • amount (number) - The payment amount to confirm

Returns

undefined

Example

Example 
ChaiPe.confirmPayment(50);
ChaiPe.generateUpiLink(options)

Generates a UPI payment link for the specified amount. Useful for creating custom payment buttons or links.

Parameters

  • options (object)
    • amount (number) - The payment amount

Returns

string - The UPI payment link

Example

Example 
const link = ChaiPe.generateUpiLink({ amount: 100 });
console.log(link);
// upi://pay?pa=yourname@upi&pn=Your+Name&am=100&cu=INR&tn=...
ChaiPe.setDarkMode(isDark)

Toggle dark mode on or off for the ChaiPe modal.

Parameters

  • isDark (boolean) - true to enable dark mode, false to disable

Returns

undefined

Example

Example 
// Enable dark mode
ChaiPe.setDarkMode(true);

// Disable dark mode
ChaiPe.setDarkMode(false);

Event Callbacks

ChaiPe provides several callback functions that you can use to track user interactions and payment events.

onNudgeShown(data)

Called when the behavioral nudge modal is displayed to the user.

Parameters

  • data (NudgeData)
    • sessionId (string) - Unique session identifier

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  onNudgeShown: (data) => {
    console.log('Nudge shown', data.sessionId);
    // Track with your analytics
    analytics.track('Nudge Shown', { sessionId: data.sessionId });
  }
});

Use Cases

  • Track when nudges are displayed for analytics
  • Measure nudge effectiveness
  • A/B test different trigger configurations
onNudgeDismissed(data)

Called when the user dismisses the nudge modal without completing a payment.

Parameters

  • data (NudgeData)
    • sessionId (string) - Unique session identifier

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  onNudgeDismissed: (data) => {
    console.log('Nudge dismissed');
    analytics.track('Nudge Dismissed', { sessionId: data.sessionId });
  }
});

Use Cases

  • Track nudge dismissal rate
  • Identify if triggers are too aggressive
  • Understand user engagement patterns
onTipCompleted(data)

Called when a user successfully completes a payment.

Parameters

  • data (TipData)
    • amount (number) - The payment amount
    • sessionId (string) - Unique session identifier
    • customData (object) - Optional collected data (email, name, phone, VPA, UTR)

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  collectEmail: true,
  collectUPIUTR: true,
  onTipCompleted: (data) => {
    console.log('Tip received!', data.amount, data.customData);
    // Send to your analytics or backend
    analytics.track('Tip Completed', {
      amount: data.amount,
      email: data.customData?.email,
      utr: data.customData?.utr
    });
  }
});

Use Cases

  • Track revenue and tips
  • Send confirmation emails
  • Update supporter database
  • Trigger thank you messages
onTipJarShown(data)

Called when the tip jar is displayed to the user.

Parameters

  • data (NudgeData)
    • sessionId (string) - Unique session identifier

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  tipJar: true,
  onTipJarShown: (data) => {
    console.log('Tip jar shown');
    analytics.track('Tip Jar Shown', { sessionId: data.sessionId });
  }
});

Use Cases

  • Track tip jar visibility
  • Measure tip jar engagement
  • Understand when users see the tip jar
onTipJarDismissed(data)

Called when the tip jar is dismissed or hidden.

Parameters

  • data (NudgeData)
    • sessionId (string) - Unique session identifier

Example

Example 
ChaiPe.init({
  upiId: 'yourname@upi',
  tipJar: true,
  onTipJarDismissed: (data) => {
    console.log('Tip jar dismissed');
    analytics.track('Tip Jar Dismissed', { sessionId: data.sessionId });
  }

Use Cases

  • Track tip jar dismissal
  • Understand user interaction patterns
  • Optimize tip jar timing and visibility
onTipJarOpened(data)

Called when the user clicks the tip jar and opens the payment modal.

Parameters

  • data (NudgeData)
    • sessionId (string) - Unique session identifier

Example

Example 
ChaiPe.init({

    console.log('Tip jar opened');

Use Cases

Themes

ChaiPe supports three built-in themes with automatic dark mode support.

Minimal Theme

Clean, centered modal with subtle design. Works well on professional sites and blogs.

Usage 
ChaiPe.init({
  theme: 'minimal'
});
Features:
  • Centered layout
  • Subtle shadows
  • Professional appearance
  • Best for content-heavy sites

Toast Theme

Compact notification-style modal. Less intrusive and good for frequent prompts.

Usage 
ChaiPe.init({
  theme: 'toast'
});
Features:
  • Compact size
  • Less intrusive
  • Good for frequent prompts
  • Minimal screen space

Floating Theme

Floating modal with shadow. More prominent and good for high-visibility prompts.

Usage 
ChaiPe.init({
  theme: 'floating'
});
Features:
  • Floating design
  • Prominent appearance
  • Strong shadows
  • High visibility
🌙
Dark Mode

All themes automatically support dark mode through CSS media queries. The theme adapts based on user's system preference. You can also force dark mode using the darkMode configuration option.

Data Types

TypeScript-style interfaces for complex data structures used in ChaiPe.

ChaiPeConfig

Configuration object passed to ChaiPe.init().

Interface 
interface ChaiPeConfig {
  // Required
  upiId: string;
  name: string;
  
  // Core options
  amounts?: number[];
  theme?: 'minimal' | 'toast' | 'floating';
  message?: string;
  buttonText?: string;
  currency?: string;
  darkMode?: boolean;
  manualOnly?: boolean;
  
  // Triggers
  triggers?: {
    scrollDepth?: number | null;
    timeOnPage?: number | null;
    exitIntent?: boolean;
  };
  
  // Data collection
  collectEmail?: boolean;
  collectName?: boolean;
  collectPhoneNumber?: boolean;
  collectVPA?: boolean;
  collectUPIUTR?: boolean;
  
  // TipJar
  tipJar?: boolean;
  tipJarPosition?: 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left';
  tipJarSize?: 'small' | 'medium' | 'large';
  tipJarColor?: string;
  tipJarIcon?: string;
  tipJarText?: string;
  tipJarAutoShow?: boolean;
  tipJarShowDelay?: number;
  tipJarShowOnMobile?: boolean;
  tipJarShowOnDesktop?: boolean;
  
  // Event callbacks
  onNudgeShown?: (data: NudgeData) => void;
  onNudgeDismissed?: (data: NudgeData) => void;
  onTipCompleted?: (data: TipData) => void;
  onTipJarShown?: (data: NudgeData) => void;
  onTipJarDismissed?: (data: NudgeData) => void;
  onTipJarOpened?: (data: NudgeData) => void;
}

Event Callback Setup 
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name',
  collectEmail: true,
  collectUPIUTR: true,
  
  // Track when nudge is shown
  onNudgeShown: (data) => {
    console.log('Nudge shown to user', data.sessionId);
    analytics.track('Nudge Shown', {
      sessionId: data.sessionId,
      timestamp: new Date().toISOString()
    });
  },
  
  // Track when nudge is dismissed
  onNudgeDismissed: (data) => {
    console.log('User dismissed nudge', data.sessionId);
    analytics.track('Nudge Dismissed', {

    });
  },
  
  // Track when tip is completed
  onTipCompleted: (data) => {
    console.log('Tip received!', data);

      amount: data.amount,
      sessionId: data.sessionId,
      email: data.customData?.email,
      utr: data.customData?.utr
    });
    
    // Send to backend
    fetch('/api/tips', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        amount: data.amount,
        email: data.customData?.email,
        utr: data.customData?.utr
      })
    });
    
    // Show thank you message
    alert('Thank you for your support!');
  },
  
  // Track tip jar interactions
  onTipJarShown: (data) => {
    analytics.track('Tip Jar Shown', { sessionId: data.sessionId });
  },
  
  onTipJarOpened: (data) => {
    analytics.track('Tip Jar Opened', { sessionId: data.sessionId });
  }
});

  const scrollPercent = (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100;
  if (scrollPercent > 50) {
    ChaiPe.updateTipJar({
      size: 'large',
      color: '#10b981',
      text: 'Enjoyed? Tip us!'
    });
  }
});

Custom Payment Links 
// Initialize ChaiPe
ChaiPe.init({
  upiId: 'yourname@upi',
  name: 'Your Name'
});

// Generate payment link for specific amount
const link = ChaiPe.generateUpiLink({ amount: 100 });

// Create custom payment button
const customButton = document.createElement('button');

customButton.addEventListener('click', () => {
  const link = ChaiPe.generateUpiLink({ amount: 50 });
  window.location.href = link;
});
document.body.appendChild(customButton);

// Create multiple payment buttons
[10, 25, 50, 100].forEach(amount => {

  });
  document.body.appendChild(button);
});
