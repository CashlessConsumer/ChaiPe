Why ChaiPe?

Everything you need to accept micropayments from your audience

🧠

Behavioral Nudging

Smart triggers based on scroll depth, time on page, and user engagement. Never interrupt - nudge at right moment.

📱

Mobile + Desktop

Deep links on mobile, QR codes on desktop. Seamless experience across all devices with automatic detection.

⚡

Zero Dependencies

~10KB minified. Pure JavaScript. No frameworks, no CDNs, no external services. Works everywhere.

🔓

PSP-less

No payment gateway needed. Direct UPI links work with GPay, PhonePe, Paytm, and all UPI apps.

🎨

3 Beautiful Themes

Minimal, Toast, or Floating. Dark mode auto-detection. Fully customizable to match your brand.

📊

Event Callbacks

Track tips with onTipCompleted. Collect email, name, phone, or UPI details optionally.

☕

Tip Jar Mode

Persistent floating button for always-visible tipping option. Non-intrusive, animated, and engaging.

Try it now →
🔄

Return Visitor Detection

Automatically detect returning visitors using localStorage. Show nudges earlier to engaged readers.

🎯

Exit Intent

Optional exit-intent detection for desktop users. Show last-chance nudge when they're about to leave.
