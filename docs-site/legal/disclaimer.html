1. Payment Processing

Frontend Library Only

ChaiPe is a frontend JavaScript library only. It provides user interface components and facilitates payment initiation, but does not process payments itself.

No Payment Gateway Integration

ChaiPe does not integrate with any payment gateway. It works directly with the Unified Payments Interface (UPI) system:

  • No merchant account required
  • No payment gateway fees
  • No transaction processing by ChaiPe
  • No payment verification infrastructure

No Backend Verification

ChaiPe does not verify payment completion. The system operates on a trust-based model:

  • Users self-confirm payment completion
  • No server-side payment verification
  • No transaction status tracking
  • No automated payment confirmation

Trust-Based System: ChaiPe relies on user honesty. There is no technical mechanism to verify whether a payment was actually completed. Website owners should implement their own verification methods if needed.

User Confirms Payment Completion

After initiating a payment:

  • Mobile: User is redirected to UPI app, completes payment, returns to confirm
  • Desktop: User scans QR code, completes payment in UPI app, confirms on website
  • Confirmation is based solely on user's statement
  • No technical verification is performed

How Payment Verification Works (or Doesn't)

▼

ChaiPe's Payment Flow:

  1. User clicks tip amount
  2. ChaiPe generates UPI deep link or QR code
  3. User is redirected to UPI app (mobile) or scans QR code (desktop)
  4. User completes payment in UPI app
  5. User returns to website and clicks "I've made the payment"
  6. ChaiPe triggers onTipCompleted callback

What ChaiPe Does NOT Do:

  • Check bank transaction status
  • Verify UPI transaction ID
  • Confirm payment amount received
  • Validate UTR (Unique Transaction Reference)
  • Communicate with payment processors

Recommendation: Collect UTR for manual verification if needed.

4. User Responsibility

Valid UPI ID Requirement

Website owners using ChaiPe are responsible for:

  • Providing a valid, active UPI ID
  • Ensuring the UPI ID can receive payments
  • Verifying the UPI ID works before going live
  • Keeping the UPI ID updated if changed

Important: If you provide an invalid UPI ID, users will not be able to send payments. ChaiPe cannot validate UPI IDs before use.

Payment Verification Responsibility

Website owners are responsible for:

  • Verifying payments if needed (manual check of bank statements)
  • Implementing their own verification systems
  • Collecting UTR for transaction tracking
  • Handling payment disputes or reversals
  • Maintaining records of received payments

UTR Collection for Verification

For payment verification, website owners should:

  • Enable UTR collection in ChaiPe configuration
  • Ask users to provide UTR after payment
  • Verify UTR against bank statements
  • Keep records of UTRs for audit purposes

Tax and Legal Compliance

Website owners are responsible for:

  • Reporting income from tips to tax authorities
  • Paying applicable taxes on received payments
  • Complying with Indian financial regulations
  • Obtaining necessary licenses or permits
  • Following RBI guidelines for digital payments
  • Complying with GST regulations if applicable

Tax Note: Income received through ChaiPe may be taxable. Consult a tax professional for advice on reporting and paying taxes on tip income.

Website Security

Website owners are responsible for:

  • Securing their website against hacking
  • Protecting user data collected through ChaiPe
  • Implementing HTTPS for secure payments

  • Protecting against XSS and other attacks

User Education

Website owners should:

  • Educate users about the trust-based payment system

ChaiPe operates within the framework of:

For tax compliance in India:
