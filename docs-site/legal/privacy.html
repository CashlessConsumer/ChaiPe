Privacy Policy

Last updated: December 29, 2024

Effective Date: December 29, 2024

ChaiPe is a client-side JavaScript library that prioritizes your privacy. We do not collect, store, or transmit any personal data to our servers. All data remains on your device and under your control.

1. Data Collection

ChaiPe is designed with privacy-first principles. We collect minimal data and only when absolutely necessary for the functionality you choose to use.

What Data We Collect

ChaiPe may collect the following information, but only if you voluntarily provide it:

  • Email Address - For sending thank-you messages or updates (optional)
  • Name - For personalized acknowledgments (optional)
  • Phone Number - For contact or verification purposes (optional)
  • VPA (Virtual Payment Address) - Your UPI ID for payment processing (optional)
  • UTR (Unique Transaction Reference) - Transaction ID for payment verification (optional)

Important: All data fields are optional. You can complete a payment without providing any personal information.

When Data Is Collected

Data is collected only when:

  • You voluntarily fill out the optional data collection form during payment
  • The website owner has enabled data collection in their ChaiPe configuration
  • You choose to provide information for a specific purpose

How Data Is Used

Any data you provide is used for:

  • Payment Processing - Facilitating UPI transactions
  • Thank-You Messages - Sending acknowledgments if email is provided
  • Analytics - Website owner's internal analytics (if configured)
  • Record Keeping - Maintaining payment records for the website owner

Data Storage

Client-Side Only: All data is stored and processed entirely on the client side. We do not have any servers, databases, or cloud storage. Your data never leaves your device unless transmitted directly to the website owner.

2. Cookies and Local Storage

Use of LocalStorage

ChaiPe uses the browser's localStorage API for the following purposes:

  • Return Visitor Detection - To recognize returning visitors and adjust behavioral nudging
  • A/B Testing - To store test group assignments for optimization experiments
  • User Preferences - To remember user choices (if configured)
  • Supporter Tracking - To remember users who have previously tipped (optional)

What Data Is Stored in LocalStorage?

▼

ChaiPe stores the following data in localStorage:

  • chaipe_visitor - Timestamp of first visit
  • chaipe_last_visit - Timestamp of last visit
  • chaipe_session_count - Number of visits
  • chaipe_ab_test - A/B test group assignment
  • chaipe_supporter - Supporter status (if enabled)

All data is stored as plain text and never transmitted to external servers.

Cookie Policy

ChaiPe does not set cookies. We use only localStorage, which is a different browser storage mechanism that:

  • Does not send data with HTTP requests
  • Has no expiration date (persists until manually cleared)
  • Is not accessible to third-party websites
  • Cannot be used for cross-site tracking

User Control Over LocalStorage

You have full control over your browser's localStorage:

  • Clear All Data: Go to browser settings → Privacy → Clear browsing data
  • Clear Site Data: Right-click → Inspect → Application → Local Storage → Right-click → Clear
  • Disable LocalStorage: Use browser extensions or settings to block localStorage
  • Incognito Mode: LocalStorage is cleared when incognito session ends

Note: Clearing localStorage will reset return visitor detection and A/B test assignments. This may affect how ChaiPe displays nudges on subsequent visits.

3. Third-Party Services

No Third-Party Analytics or Tracking

ChaiPe does not use any third-party services by default:

  • ❌ No Google Analytics
  • ❌ No Facebook Pixel
  • ❌ No Hotjar or similar tools
  • ❌ No advertising networks
  • ❌ No data brokers

Privacy-First Design: ChaiPe is self-contained with zero external dependencies. No third-party scripts, trackers, or analytics are loaded.

UPI App Integration

When you make a payment through ChaiPe:

  • You are redirected to your chosen UPI app (GPay, PhonePe, Paytm, etc.)
  • The transaction occurs directly between your UPI app and the recipient's bank
  • ChaiPe has no access to your UPI app or transaction details
  • Each UPI app has its own privacy policy that applies to your use of that app

No Data Sharing

We do not share any data with third parties because:

  • We don't collect data to share
  • We don't have servers to store or transmit data
  • We don't have partnerships with data brokers
  • We don't sell or monetize user data

Website Owner Responsibility

While ChaiPe itself doesn't use third-party services, the website implementing ChaiPe may:

  • Use their own analytics (Google Analytics, etc.)
  • Integrate with their own CRM or email marketing tools
  • Have their own privacy policy that applies to data they collect

Please review the website owner's privacy policy for information about their data practices.

4. Data Security

Client-Side Processing Only

ChaiPe's architecture ensures maximum security:

  • No Server Storage: No data is ever sent to ChaiPe servers
  • No Data Transmission: No data leaves your device except to the website owner
  • No Databases: We don't have any databases to breach
  • No Cloud Storage: No data is stored in the cloud

Security by Design: By not storing any data, we eliminate the risk of data breaches, hacking, or unauthorized access.

HTTPS Requirements

ChaiPe requires HTTPS for secure operation:

  • All payment links use HTTPS protocol
  • UPI deep links are encrypted by the UPI protocol
  • QR codes contain HTTPS payment URLs
  • Data transmission to website owner is encrypted

Data Encryption

Payment data is protected by:

  • UPI Standard Encryption: All UPI transactions use bank-grade encryption
  • TLS/SSL: HTTPS ensures encrypted data transmission
  • QR Code Security: QR codes contain only payment parameters, not sensitive data

Security Best Practices

We recommend the following security practices:

  • Only provide payment information on HTTPS websites
  • Verify the recipient's UPI ID before making payments
  • Keep your UPI app updated with the latest security patches
  • Use strong authentication on your UPI app
  • Review your UPI transaction history regularly

Important: ChaiPe is a frontend library. We cannot guarantee the security of websites that implement ChaiPe. Always verify you're on a legitimate website before making payments.

5. User Rights

You have the following rights regarding your data:

Right to Not Provide Data

All data collection in ChaiPe is completely optional:

  • You can make payments without providing any personal information
  • You can skip all optional data collection fields
  • No functionality is withheld for not providing data
  • You can dismiss nudges without providing any information

Right to Clear LocalStorage

You have the right to clear your browser's localStorage at any time:

  • Clear all browsing data in browser settings
  • Clear site-specific data in developer tools
  • Use incognito/private browsing mode
  • Use browser extensions to manage localStorage

Right to Request Data Deletion

If you have provided data to a website using ChaiPe:

  • Contact the website owner directly to request data deletion
  • Clear your localStorage to remove client-side data
  • For GDPR requests, contact the website owner's designated representative

Right to Opt Out

You can opt out of data collection by:

  • Not filling out optional data fields
  • Clearing your localStorage regularly
  • Using browser settings to block localStorage
  • Disabling JavaScript (though this prevents ChaiPe from functioning)

Right to Access

You can access data stored in localStorage by:

  • Opening browser developer tools (F12)
  • Navigating to Application → Local Storage
  • Viewing the ChaiPe keys and their values

Right to Portability

You can export your localStorage data:

  • Use developer tools to copy localStorage contents
  • Use browser extensions to export localStorage
  • Request data export from the website owner

6. GDPR Compliance

ChaiPe is designed to comply with the General Data Protection Regulation (GDPR) for users in the European Union.

EU User Protections

EU users are entitled to enhanced protections:

  • Explicit consent before data collection
  • Right to be forgotten (data deletion)
  • Right to data portability
  • Right to access and rectify data
  • Right to object to processing
  • Right to restrict processing

Data Minimization Principle

ChaiPe follows GDPR's data minimization principle:

  • We collect only data that is absolutely necessary
  • All data collection is optional
  • We do not collect data by default
  • We do not store data beyond what's needed

Privacy by Design: ChaiPe's architecture inherently complies with GDPR principles by not storing or transmitting data to our servers.

Consent Mechanisms

Consent is obtained through:

  • Opt-in Forms: Data collection forms are clearly marked as optional
  • Clear Labels: Each field explains what data is collected and why
  • No Pre-filled Fields: No data is collected without explicit user action
  • Easy Withdrawal: Users can clear localStorage anytime to withdraw consent

Data Subject Rights

As a data subject under GDPR, you have the right to:

  • Access: Know what data is collected and how it's used
  • Rectification: Correct inaccurate data
  • Erasure: Request deletion of your data
  • Restrict Processing: Limit how your data is used
  • Data Portability: Receive your data in a machine-readable format
  • Object: Object to processing of your data

Lawful Basis for Processing

ChaiPe's lawful basis for processing is:

  • Consent: Explicit user consent for optional data collection
  • Legitimate Interest: Payment processing and user experience improvement

Data Transfers

ChaiPe does not transfer data outside the EU because:

  • We don't have servers to transfer data to
  • All data remains on the user's device
  • Any data transfer is to the website owner, who is responsible for GDPR compliance

Contact for GDPR Inquiries

For GDPR-related inquiries, please contact:

  • The website owner implementing ChaiPe (primary contact)
  • ChaiPe project maintainers via GitHub Issues
  • Your local data protection authority for escalations

7. Children's Privacy

No Collection from Children Under 13

ChaiPe is not intended for use by children under the age of 13. We do not knowingly collect personal information from children under 13.

Parental Consent Requirements

If a child under 13 provides personal information:

  • Parents or guardians should contact the website owner immediately
  • Request deletion of the child's data
  • Review the website's privacy policy for specific procedures

COPPA Compliance

ChaiPe is designed to comply with the Children's Online Privacy Protection Act (COPPA):

  • We do not target children under 13
  • We do not collect personal information from children
  • All data collection is optional and requires user action
  • We do not use data for marketing to children

Parental Responsibility: Parents should monitor their children's online activities and educate them about not providing personal information online.

Website Owner Responsibility

Websites implementing ChaiPe are responsible for:

  • Ensuring compliance with children's privacy laws
  • Obtaining parental consent when required
  • Providing clear privacy notices
  • Implementing age verification if necessary
