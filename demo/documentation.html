🚀 Quick Start

Get started with ChaiPe in just a few lines of code:

Basic Setup
// 1. Include ChaiPe (see Installation above)

// 2. Initialize with your configuration
ChaiPe.init({
  upiId: 'srikanthlogic@icici',
  name: 'Srikanth',
  note: 'Contributing to ChaiPe itself for its work',
  amounts: [10, 25, 50, 100],
  theme: 'minimal'
});

// 3. That's it! ChaiPe will handle the rest
💡 Tip: Check out the Interactive Playground to experiment with different configurations in real-time.

⚙️ Configuration

All configuration options are passed to ChaiPe.init():

Parameter Type Required Default Description
upiId string Yes null Your UPI ID (e.g., yourname@upi)
name string Yes null Display name shown to users
amounts number[] No [10, 25, 50, 100] Preset tip amounts in rupees
theme string No 'minimal' Theme: 'minimal', 'toast', or 'floating'
message string No 'Support my work' Custom message displayed in modal
buttonText string No 'Tip' Text shown on tip button
currency string No 'INR' Currency code (3-letter ISO code)
darkMode boolean No true (auto-detect) Force dark/light mode
tipJar boolean No false Show persistent tip jar button
manualOnly boolean No false Disable automatic triggers
triggers object No See below Behavioral trigger configuration

Trigger Configuration

The triggers object configures when the nudge appears:

Parameter Type Default Description
scrollDepth number 70 Trigger when user scrolls to X% of page (0-100)
timeOnPage number 120 Trigger after X seconds on page
exitIntent boolean false Trigger on exit intent (desktop only)

Data Collection Options

Optional fields to collect from users:

Parameter Type Default Description
collectEmail boolean false Collect email address
collectName boolean false Collect user's name
collectPhoneNumber boolean false Collect phone number
collectVPA boolean false Collect UPI VPA (Virtual Payment Address)
collectUPIUTR boolean false Collect UPI transaction reference number

📚 API Reference

ChaiPe.init(config)

Initialize ChaiPe with configuration. Creates singleton instance on first call, reuses on subsequent calls.

ChaiPe.init(config: ChaiPeConfig): void
Example
ChaiPe.init({
  upiId: 'srikanthlogic@icici',
  name: 'Srikanth',
  note: 'Contributing to ChaiPe itself for its work',
  amounts: [10, 25, 50],
  theme: 'minimal'
});

ChaiPe.show()

Manually show the tip modal. Useful for custom trigger logic or button click.

ChaiPe.show(): void
Example
// Show modal on button click
document.getElementById('tip-button').addEventListener('click', () => {
  ChaiPe.show();
});

ChaiPe.setDarkMode(isDark)

Programmatically toggle dark/light mode after initialization.

ChaiPe.setDarkMode(isDark: boolean): void
Example
// Toggle dark mode based on system preference
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
ChaiPe.setDarkMode(prefersDark);

🎨 Themes

ChaiPe includes three beautiful, responsive themes:

Minimal

Clean, centered modal. Best for blogs and articles.

{
  theme: 'minimal'
}

Toast

Bottom-positioned toast. Non-intrusive, quick to dismiss.

{
  theme: 'toast'
}

Floating

Floating bar at bottom. Always visible, minimal footprint.

{
  theme: 'floating'
}
💡 Tip: All themes automatically support dark mode via prefers-color-scheme media query.

📡 Callbacks

Track user interactions with event callbacks:

onNudgeShown(data)

Called when the nudge/modal is displayed to the user.

onNudgeShown: (data: NudgeData) => void
Example
ChaiPe.init({
  onNudgeShown: (data) => {
    console.log('Nudge shown!', data);
    // Track with analytics
  }
});

onNudgeDismissed(data)

Called when user dismisses the modal without tipping.

onNudgeDismissed: (data: NudgeData) => void
Example
ChaiPe.init({
  onNudgeDismissed: (data) => {
    console.log('Nudge dismissed', data);
  }
});

onTipCompleted(data)

Called when user completes a tip payment. This is the most important callback for tracking revenue.

onTipCompleted: (data: TipData) => void
Example
ChaiPe.init({
  onTipCompleted: (data) => {
    console.log('Tip received!', data);
    // Send to analytics backend
    fetch('/api/tips', {
      method: 'POST',
      body: JSON.stringify(data)
    });
  }
});
Property Type Description
sessionId string Unique session identifier
amount number Tip amount in rupees
timestamp string ISO 8601 timestamp
email string | null User's email (if collected)
name string | null User's name (if collected)
phone string | null User's phone (if collected)
vpa string | null User's UPI VPA (if collected)
utr string | null UPI transaction reference (if collected)

🔧 Advanced Usage

Custom Trigger Logic

Disable automatic triggers and implement your own logic:

Custom Scroll Trigger
ChaiPe.init({
  upiId: 'srikanthlogic@icici',
  name: 'Srikanth',
  note: 'Contributing to ChaiPe itself for its work',
  manualOnly: true
});

// Custom scroll trigger at 50%
window.addEventListener('scroll', () => {
  const scrollPercent = getScrollPercent();
  if (scrollPercent >= 50) {
    ChaiPe.show();
  }
}, { passive: true });

Integration with Analytics

Send tip data to your analytics platform:

Google Analytics
ChaiPe.init({
  upiId: 'srikanthlogic@icici',
  name: 'Srikanth',
  note: 'Contributing to ChaiPe itself for its work',
  onTipCompleted: (data) => {
    // Track with Google Analytics 4
    gtag('event', {
      event_category: 'tip',
      event_label: '₹' + data.amount
    });
    
    // Track with Mixpanel
    mixpanel.track('Tip Completed', {
      amount: data.amount,
      email: data.email
    });
  }
});

A/B Testing

Test different configurations to optimize conversion:

A/B Test Themes
// Randomly assign theme for A/B testing
const themes = ['minimal', 'toast', 'floating'];
const randomTheme = themes[Math.floor(Math.random() * themes.length)];

ChaiPe.init({
  upiId: 'srikanthlogic@icici',
  name: 'Srikanth',
  note: 'Contributing to ChaiPe itself for its work',
  theme: randomTheme,
  onTipCompleted: (data) => {
    // Track which theme converted
    analytics.track('Tip Completed', {
      theme: randomTheme,
      amount: data.amount
    });
  }
});

❓ FAQ

Is ChaiPe free to use?

Yes! ChaiPe is open source under the MIT license. You can use it in personal and commercial projects without any fees.

Do I need a payment gateway?

No! ChaiPe uses direct UPI links. You just need a valid UPI ID from your bank or UPI app.

How do I receive payments?

Payments go directly to your UPI ID. You'll see them in your bank account or UPI app just like any other UPI transaction.

Can I verify payments?

ChaiPe is trust-based - it doesn't verify payments with a backend. Users self-confirm they've paid. For verification, you can collect the UTR (Unique Transaction Reference) and cross-reference with your bank statement.

What browsers are supported?

ChaiPe works in all modern browsers (Chrome, Firefox, Safari, Edge) that support ES6+. It does not work in IE11 or older browsers.

Is ChaiPe accessible?

Yes! ChaiPe follows WCAG AA accessibility guidelines. It supports keyboard navigation, screen readers, and proper ARIA labels.

How large is the library?

The minified version is ~10KB. Gzipped, it's under 4KB. It loads instantly even on slow connections.

Can I customize the styling?

Yes! While ChaiPe includes three beautiful themes, you can override the CSS by targeting the .ChaiPe-* class names. See the source code for the complete class list.
