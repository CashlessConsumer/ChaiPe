Explore how ChaiPe handles edge cases, errors, and advanced scenarios

❌ Error Scenarios

⚠️ Missing Required Fields
upiId and name are required. Without them, ChaiPe will throw an error.
⚠️ Invalid Trigger Values
Scroll depth must be 0-100, time on page must be positive integer. Invalid values are ignored.
⚠️ Not Initialized
Calling ChaiPe.show() before init() will throw an error.
⚠️ Browser Compatibility
ChaiPe requires ES6+ support. Will not work in IE11 or older browsers.
⚠️ localStorage Disabled
If user has disabled localStorage, return visitor detection won't work. Gracefully degrades.

✅ Best Practices

Always Validate UPI ID

Ensure your UPI ID is valid and active before deploying. Test with a small payment first.

Start Conservative

Begin with higher trigger thresholds (70% scroll, 2+ minutes). Lower gradually based on analytics.

Test All Themes

Try all three themes to see which works best for your content and audience.

Monitor Callbacks

Use onTipCompleted to track conversion rates and optimize your strategy.

Respect User Privacy

Only collect data you actually need. Be transparent about how you use it.

Handle Errors Gracefully

Wrap ChaiPe initialization in try-catch to handle potential errors gracefully.
